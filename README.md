# mujina-research

Research repository tracking firmware benchmarks, protocol gaps, and open issues
across Bitcoin mining infrastructure.

## Layout

| Path | Purpose |
|------|---------|
| `research/` | Per-platform issue tracking and firmware benchmarks |
| `tracking/` | Work-in-progress and completed PR log |
| `specs/` | Protocol and hardware specification analysis |
| `ROADMAP.md` | Milestone planning |
| `BACKLOG.md` | Unscheduled ideas and deferred work |
